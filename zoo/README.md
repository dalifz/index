# 玉谷萬獸園 · Zoo Structure Tools วังมังกร

เครื่องมือวางแผนสวนสัตว์ใน **Planet Zoo 2** — สวนสัตว์หุบเขาหยก 136 ชนิด 8 โซน

เปิด [`web/index.html`](web/index.html) ได้เลย

- **แผนผัง** ภาพวาดหมึกจีน-สีน้ำ พร้อม headshot ทุกตัว ซูม/คลิกดูรายละเอียด export PNG 4000×2500 และภาพโพสต์ 1080×1350
- **เลเวล** ลำดับสร้างสวนตั้งแต่เริ่มเซฟ 7 ขั้น พร้อมเช็กลิสต์
- **อุณหภูมิ** ใส่อุณหภูมิแผนที่ → บอกว่ากรงไหนต้อง Heater/Cooler
- **จับคู่สัตว์** เช็กว่าเลี้ยงรวมกรงได้ไหม (Thriving/Neutral, อุณหภูมิ, พื้นที่รวม)
- **เส้นทางเดิน** และ **ทะเบียนสัตว์** ทั้งหมด

ข้อมูลและรูปสัตว์จาก [Zoopedia ทางการ](https://www.planetzoogame.com/2/zoopedia) © Frontier Developments — โปรเจกต์ส่วนตัว ไม่เกี่ยวข้องกับ Frontier
